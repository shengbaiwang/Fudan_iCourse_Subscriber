# iCourse · 九个蓝色三角形底稿

九个独立底稿结合第一版的简明后现代几何与第二版的深蓝单色层次。文学意象来自 Anne Carson《Short Talk on the Total Collection》，视觉延伸围绕保存、分类、缺失与浪潮展开。名称与描述是设计解读，不是原诗的固定释义。

打开 gallery.html 查看九宫格、32/64 像素预览与原图放大。点击图像放大；点击圆点标记候选。放大时可使用左右方向键切换，Esc 关闭。

| 编号 | 名称 | 方向 |
|---|---|---|
| 01 | 余隙 | 四块几何围住一处偏心留白，完整中保留空缺。 |
| 02 | 折潮 | 三个折叠般的三角形形成上涌的节奏。 |
| 03 | 静列 | 重复的三角形略有高低，呈现安静的分类秩序。 |
| 04 | 阈 | 两枚三角形之间的窄隙，像进入资料库的门槛。 |
| 05 | 悬置 | 三块蓝色之间留下一个未被填满的位置。 |
| 06 | 未满 | 整齐的五枚三角形，把缺失本身留在构图里。 |
| 07 | 回流 | 相反方向的三角形，让秩序产生内向的回旋。 |
| 08 | 深藏 | 蓝色几何收拢成三角轮廓，深色细缝藏在内部。 |
| 09 | 界外 | 三枚整齐排列，一枚轻轻偏离，留下不可归类的部分。 |

## 文件与生成方式

- 01.png 至 09.png：九张最终选入的独立 PNG 底稿。
- gallery.html：本地对比页。
- contact-sheet.png：对比页的静态截图，包含编号和名称，未修改独立图标原图。
- prompts.md：各稿使用的完整生成提示词。

所有底稿通过内置 image_gen 生成。01–06 初稿使用前两版作为视觉参考；03、04、08 进行了几何修正。其余弃稿保留在生成目录，没有混入这组交付文件。此组为图标底稿，未替换现有应用图标。
